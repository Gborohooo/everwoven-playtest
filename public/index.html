Keep bugs, design ideas, and testing results in the private feedback backlog rather than losing them in chat. GitHub access is required separately from this website login.

Report a bug

Start the issue title with [Bug] and include:

  • The build version you tested.
  • What happened and what you expected.
  • Steps to reproduce it, if known.
  • A screenshot, video, or relevant log excerpt.

Remove personal information from logs. Do not post passwords, access codes, or tokens.

Write a bug report

Suggest a feature

Start the issue title with [Idea] and explain:

  • The experience or problem you want to improve.
  • Your proposed behavior.
  • Why it would make the game better.
  • Any tradeoffs or alternatives worth considering.

Suggestions are discussion items, not commitments. Approved scope and priorities are decided separately.
