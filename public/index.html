Release notes, package hash & compatibility guidance

This week's testing focus

  1. Create a new disposable world.
  2. Check startup, menus, terrain rendering, and movement.
  3. Change a HUD preference and quit normally.
  4. Restart, confirm the preference survived, and reload the world.

These checks passed on the owner's machine. Testing on another computer is still needed. Do not delete, move, or migrate existing saves for this test.

Always include the build version with a report. Do not assume an older build can safely open a newer save.

2026-11-04 · Private prerelease

First Windows playtest

First published package, not a complete historical game changelog. Packaging and uploaded-download hashes were verified. Owner accepted terrain rendering, movement, test-world reload, and HUD-preference persistence across restart.

  • Known warnings on the tested machine: Vulkan loader registry layer-manifest lookup and RGB8-to-RGBA8 texture conversion. The requested owner playtests passed.
  • Current portable-playtest documentation lists persistent distant foliage history as unfinished.
  • Release saves use %APPDATA%\Everwoven; development-editor data remains separate. Use a new disposable world. Arbitrary older/newer-world compatibility and second-computer compatibility are not established.

Report a bug

Start the issue title with [Bug] and include:

  • The build version you tested.
  • What happened and what you expected.
  • Steps to reproduce it, if known.
  • A screenshot, video, or relevant log excerpt.

Remove personal information from logs. Do not post passwords, access codes, or tokens.
